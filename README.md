Репозиторий для курса "Проектный менеджемент" ФКН ВГУ

## Фазы

| Фаза | Папка | Содержание |
|---|---|---|
| 1. Выбор концепции | `phase-1` | 4+ проектных альтернатив, 4+ критерия, трёхточечные экспертные оценки, коллективный нечёткий TOPSIS, чёткий МАИ, сопоставление результатов. |
| 2. Распределение работы | `phase-2` | Декомпозиция третьей фазы, оценки сложности, предпочтения исполнителей, формальная постановка задачи распределения и её решение. |
| 3. Оценка проекта | `phase-3` | 10+ Use Cases, расчёты COSMIC FP и UCP, коллективная экспертная оценка, обоснование масштаба проекта, состава команды и продолжительности разработки. |
| 4. Прогнозирование | `phase-4` | Трёхточечные оценки работ пятой фазы, две модели Монте-Карло, анализ недельной производительности и трудозатрат, срок с уровнем доверия 80%. |
| 5. Планирование | `phase-5` | Перечень работ, характеристики ресурсов, зависимости задач, сравнение эвристик и итоговый календарный график. |
